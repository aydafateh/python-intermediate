## ▶️ Getting Started

### Requirements

- Python 3 installed on your computer
- A code editor, such as Visual Studio Code
- Basic familiarity with the terminal

### Run a Project

**1. Clone the repository:**

```bash
git clone https://github.com/aydafateh/python-intermediate.git
```

**2. Open the repository:**

```bash
cd python-intermediate
```

**3. Navigate to a project folder:**

For example:

```bash
cd 06_email-analyzer
```

**4. Run the Python file:**

```bash
python main.py
```

Replace `main.py` with the actual Python filename in the selected project.

## 🧠 My Learning Approach

I follow a project-based learning approach:

1. Understand the requirements.
2. Break the problem into smaller steps.
3. Implement the solution using Python.
4. Test different inputs and edge cases.
5. Debug mistakes and improve the code.
6. Document the project and track my progress.

The goal is not simply to make a program work. It is to understand *why* it works and how to make it better.
